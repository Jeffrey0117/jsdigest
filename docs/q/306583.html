How to get the children of the $(this) selector?

2.4k2008 年提問 · Alex ·javascriptjqueryjquery-selectors 在 Stack Overflow 看原文 ↗

I have a layout similar to this, and would like to use a jQuery selector to select the child img inside the div on click.

<div id="...">
  <img src="...">
</div>

To get the div, I've got this selector:

$(this)

How can I get the child img using a selector?

3k採納 by Simon 原文 ↗

The jQuery constructor accepts a 2nd parameter called context which can be used to override the context of the selection. 

jQuery("img", this);

Which is the same as using .find() like this:

jQuery(this).find("img");

If the imgs you desire are only direct descendants of the clicked element, you can also use .children():

jQuery(this).children("img");
496 by philnash 原文 ↗

You could also use

$(this).find('img');

which would return all imgs that are descendants of the div

149 by rakslice 原文 ↗

If you need to get the first img that's down exactly one level, you can do 

$(this).children("img:first")
